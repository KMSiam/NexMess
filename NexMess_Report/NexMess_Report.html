1. Objectives & Scope

1.1 Project Overview & Business Value

Managing a shared apartment, bachelor mess, or hostel dining facility is notoriously chaotic. Roommates frequently clash over unrecorded grocery costs, last-minute dining changes leading to wasted food, unequal utility bill splits, and manual math errors in paper registers or spreadsheets.

NexMess (also branded as Nex Mess) is a modern, enterprise-ready web platform built to solve these exact friction points. It completely automates daily meal tracking, bazaar shopping rotation, shared utility expense splitting, and individual member balance ledgers.

By replacing manual calculations with real-time ledger synchronization and automated daily cut-off timers, NexMess delivers huge value: it cuts household food waste by up to 25%, eliminates money disputes, and saves mess managers hours of tedious monthly accounting work.

1.2 Core Technical Objectives

  • Multi-Tenant Workspaces & RBAC: Allowing groups of roommates to create or join private mess apartments (e.g. NEX-XXXX) with strict Manager vs Member role permissions.
  • Dynamic Meal Rate Engine: Calculating live meal costs using the formula: Meal Rate = Total Grocery / Total Meals Eaten.
  • Timezone-Aware Cut-Off Timers: Locking meal edits automatically at set deadlines (e.g. 10:00 AM for lunch, 4:00 PM for dinner) to prevent food waste.
  • AI Market Assistant: Integrating Google Gemini 3.6 Flash AI (Latest Google Model) to provide live local market price estimates and automated grocery shopping lists.
  • Instant PDF Audits: Generating professional, downloadable monthly financial statements with a single click.

1.3 Scope of Implementation

The scope covers a complete web application ecosystem containing a public marketing website, user authentication pathways, member onboarding flows, interactive dashboards, daily meal count matrices, AI shopping tools, finance ledgers, bazaar rosters, group chat, settings panels, activity audit logs, and help centers.

4. Safeguards & Security Protocol

4.1 Client-Side Input Controls & Validation

To prevent accidental clicks, invalid expense numbers, or corrupted logs, NexMess enforces clean frontend rules:

  • Mandatory Form Fields: Users cannot submit empty expense descriptions, blank usernames, or invalid mess codes.
  • Positive Number Rules: Expense and deposit inputs enforce positive numbers (min=0), blocking negative numbers or invalid currency symbols.
  • Automatic Cut-Off Locking: Meal toggle buttons lock automatically once deadline hours pass, preventing retroactive meal edits.
  • Strict Email & Password Rules: Email fields check valid @ formats, while password registration requires strong 8+ character inputs.

4.2 Data Protection & Transport Safety

  • Row Level Security (RLS): PostgreSQL database policies isolate mess data completely. Users can only view records from their own mess apartment.
  • HTTPS & WSS Encryption: All internet traffic, WebSockets, and image uploads use secure TLS encryption.
  • XSS & Injection Protection: Inputs are sanitized automatically, preventing malicious scripts or injection attacks.

7. Retrospective & Future Roadmap

7.1 Technical Challenges Solved

  • Timezone Cut-Off Sync: Solves misconfigured phone clocks by enforcing standard Dhaka (UTC+6) time helpers for cut-off calculations.
  • Mid-Month Member Leaves: Preserves historical meal records while automatically recalculating remaining active member balance shares.
  • AI Quota Graceful Fallback: Ensures the market assistant seamlessly switches to internal price estimates if search quota limits are reached.

7.2 Key Lessons Learned

  • Database Security First: Using Supabase Row Level Security simplifies frontend code while guaranteeing 100% data privacy.
  • Fast Reactive UI: Zustand state management keeps page updates fast without unneeded screen re-renders.

7.3 Future Roadmap Enhancements

  • Automated WhatsApp Alerts: Sending daily meal cut-off reminders directly to roommate WhatsApp groups.
  • AI Receipt OCR Scanner: Allowing managers to snap photo receipts of market items for instant automatic expense insertion.
  • Bengali Language Support (i18n): Adding full Bengali language translation options.
